# そらブラ — 棒人間の空中ブランコ

棒人間を空中ブランコで左から右へ飛ばしていくゲームです。
**音だけでも、絵だけでも**「手をはなすタイミング」がわかるようにしてあるので、全盲の人も、聞こえにくい人も同じルールで遊べます。

## 遊び方

- ゆれに合わせて「キュイーン」と音が高くなっていき、**いちばん高い「キン!」** で手をはなす(そのあと下がって、ブランコ1往復で音も1周)
- 絵では、上のランプ「1・2・3・今」、手のまわりでちぢむ輪、はなす位置の「ここ」マークで同じタイミングがわかる
- 下のタイミングバー(針がまん中に来たら「今」)は、せっていでオンにできる。オンのときは点数 ×0.8 で、ランキングに「バーあり」と出る(れんしゅうは点数そのまま)
- スペース / Enter / 画面タップ / 「はなす」ボタン で手をはなす。Esc で一時停止

| 判定 | ずれ | どうなる |
|---|---|---|
| ★ クリティカル | 0.07秒以内(30回つかまるまでにだんだんせまくなり、最後は0.04秒) | ブランコを1つ飛ばして大ジャンプ。点も大きい |
| ◎ ナイス | 0.16秒以内(最後は0.11秒) | つぎのブランコへ |
| ○ セーフ | 0.3秒以内(最後は0.23秒) | なんとかつかまる |
| × ミス | それ以上 | ネットに落ちたらおしまい(一発勝負)。れんしゅうなら何回でもやり直せる |

連続成功でコンボ倍率アップ。進むほどブランコが速くなり(1往復2.4秒 → 1.0秒)、15回目からはブランコごとに速さが最大±15%変わります。

## アクセシビリティ

- 合図の音(上がっていく音と「キン!」)は Web Audio の時計で予約して鳴らすので、画面がカクついても音はずれない
- ゆれる音の左右(パン)と大きさで、今どこにいるか耳でわかる
- 判定の音は種類ごとに別の音。設定で「ゲーム中の声」(読み上げ)もON/OFFできる
- 色だけに頼らず、記号(★◎○×)・形(「今」だけ四角)・文字でも区別できる。配色は Okabe-Ito ベース
- スマホは合図に合わせて振動(Android)
- 「タイミング補正」で Bluetooth イヤホンなどの音の遅れを調整できる
- 「動きを減らす」で回転などを止められる
- メニューは全部ふつうのボタンなので、スクリーンリーダーとキーボードだけで操作できる
- Windowsのハイコントラストに対応。ゲーム画面もシステムの色(背景・文字・強調色)だけで描き、判定の幅は色ではなく「枠・しま模様・塗り」で区別する
- 結果は見出しにフォーカスが移ったときに全部読まれる形にしてあるので、ライブリージョン(aria-live)の読み上げが弱いスクリーンリーダーでも読める
- ゲーム中は S キーでスコア・きょりを読み上げ

## ランキング

アイクエと同じしくみです(Google Apps Script + スプレッドシート)。

- ニックネーム + パスワードでログイン(はじめての名前ならそのまま登録)。ゲストでも遊べるけど、オンラインランキングには入らない
- **今期**(1日〜15日 / 16日〜月末で区切る)と **歴代** のタブ。2026年11月1日〜15日が第1回(それより前はプレ期間で、王者はつかない)
- 前の期の1位には赤い「**第〇回王者**」の称号
- 送れなかったスコアは端末に取っておいて、あとで送り直す
- サーバー側:合言葉チェック、ロック、キャッシュ、パスワード10回まちがいで10分ロック、ありえないスコアをはじく

### サーバーの準備

1. https://script.google.com で新しいプロジェクトを作り、`ranking_server.gs` を全部貼り付ける
2. `SECRET` と `TOKEN_SALT` を自分だけの合言葉に書きかえて保存
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行するユーザー「自分」、アクセスできるユーザー「全員」
4. 出てきた URL(`…/exec`)を `index.html` の `CONFIG.SERVER_URL` に、`SECRET` と同じ文字を `CONFIG.KEY` に書く

`SERVER_URL` が空のままなら、その端末だけのランキングで動きます(テスト用)。

## ファイル

```
sorabura/
├── index.html         … ゲーム本体(これ1つで動く)
├── ranking_server.gs  … ランキングサーバー(GAS)
└── README.md
```

GitHub Pages に置く場合は、`index.html` をリポジトリの一番上に置いて Pages を有効にするだけです。
